# Kanad S.H.I.E.L.D. 2026 — Submission Abstracts

Five hackathon submission abstracts for the **Kanad S.H.I.E.L.D. 2026** hackathon
(Cyber Crime Branch, Ahmedabad City). **Submission deadline: 20 June 2026.**

All five frame the **same VisionScan / CityShield platform** (one codebase) against
a different official problem statement: each abstract presents the relevant module
as the product and the rest as integrated companion modules. Every abstract follows
the required structure — Proposed Solution, Methodology, Tools & Technologies — and
explicitly addresses its own problem statement's evaluation criteria.

---

**Platform modules referenced across the abstracts:** VisionScan (CCTV semantic
search) · Anomaly Watch (CLIP+YOLO incident detection) · CityShield (JWT/RBAC cases,
complaints, notifications, analytics) · Arbiter (RAG legal AI, en/hi/gu) · CrimeGPT
(document automation) · GovIntel (legal/government feed) · Ahmedabad GIS (react-
leaflet, 30 localities) · predictive risk scoring · NN+2-opt patrol routing ·
Phase-3 security hardening (OWASP middleware, rate limiting, prompt-injection guards,
lockdown, pytest suite).

> Demonstration disclaimer: neighbourhood-level crime intensities and the synthetic
> incident dataset are editorial estimates compiled from public sources (NCRB/press)
> for demonstration only — not official crime ratings of any area. AI outputs are
> investigative decision-support and require officer verification.
